# Mehtagent problem reports

Problems people hit while setting up or using Mehtagent. Most reports here are filed from inside the app, under the
person's own GitHub account, so we can reply to them here.

What a report contains: which check failed, its message, the Mehtagent version, the macOS version and the edition.
It never contains prompts, files, file paths, email addresses or keys. The app removes those and refuses to send a
report that still has any.

Each report carries an id like `MI-123`. We use it to match the report with the fix, and the app tells you when the
version that fixes it is ready.

To report something by hand, open a new issue and use the form.
